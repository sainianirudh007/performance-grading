# Student Result Management System

## 1. Project Overview

The **Student Result Management System** is a simple Python-based project used to store and manage student academic results.

The project stores student information such as:
- Student name
- Roll number
- Marks in subjects
- Total marks
- Percentage
- Grade

Student data is stored in a text file (`students.txt`), making the project simple and suitable for a beginner-level Python project.

## 2. Features

The system provides the following menu options:

1. **Add Student** – Add a new student's details and marks.
2. **Display All Students** – Display the result details of all students.
3. **Search Student** – Search for a student using available student information.
4. **Update Marks** – Update the marks of an existing student.
5. **Delete Student** – Delete a student's record.
6. **Show Topper** – Find and display the student with the highest result.
7. **Exit** – Save the required data and close the program.

## 3. Project Structure

### File Description

- **main.py** – Contains the main menu and controls the program.
- **student.py** – Contains the student-related class/data and operations.
- **result_utils.py** – Contains functions used for calculating and displaying results.
- **students.txt** – Stores student records.
- **README.md** – Contains information about the project.
- **__pycache__/** – Automatically generated by Python for bytecode files. It is not part of the main project logic.

## 5. Grading System

The program calculates the total marks and percentage and assigns a grade according to the percentage.

The grade rules used by the project are:

| Percentage | Grade |
|---|---|
| 90% and above | A+ |
| 80% – 89% | A |
| 70% – 79% | B |
| 60% – 69% | C |
| 50% – 59% | D |
| Below 50% | F |

## 6. How to Run the Project

1. Open the project folder in **Visual Studio Code**.
2. Make sure Python is installed.
3. Open the VS Code terminal.
4. Run:

```bash
python main.py
```

5. Select an option from the displayed menu.
6. Follow the instructions shown in the terminal.
